# Homebrew tap for SpanDock

```bash
brew install --cask spandock/spandock/spandock   # the Mac app (asks server or client on first launch)
brew install spandock/spandock/spandock          # the command-line binary (macOS or Linux)
```

- The app updates itself (`brew upgrade --greedy` works too).
- The command-line install updates with `brew upgrade spandock`, and runs as a background service with `brew services start spandock` after you choose its mode once (see `brew info spandock`).

The cask and formula are generated by SpanDock's release workflow; changes here are overwritten. Releases: <https://github.com/SpanDock/spandock-releases>.
